# Skydive South Texas

Public site, load clock, and manifest for the Mustang Island dropzone.

- Tandem bookings with a deposit, and the balance collected at check-in
- Fun jumper accounts you can add money to, then spend on a jump ticket
- Staff manifest: loads, call times, and who is on each load
- Audit log of desk actions
- Card payments run in Stripe test mode (4242 4242 4242 4242) until a live Stripe account is connected. Nothing is charged.

Hangar #1, 139 Piper Blvd, Port Aransas, TX.
